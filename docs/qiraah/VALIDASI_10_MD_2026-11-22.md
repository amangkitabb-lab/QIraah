## Cara membaca hasil

- Sumber pengguna: sepuluh Markdown yang diunggah, `manifest.json` (status `partial`). Analisis ini benar-benar membaca file Markdown yang terpasang, mengunci checksum SHA-256 setiap MD, dan mengecek penanda halaman. **PDF asli pengguna tidak tersedia sebagai file dalam sesi ini.**
