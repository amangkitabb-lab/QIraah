QIRAAH V2.8: PAKET WEBSITE PUBLIK

1. Download, ekstrak, lalu letakkan SELURUH ISI folder ZIP di root branch main repo amangkitabb-lab/QIraah. Jangan upload file ZIP-nya.
2. Pastikan Settings > Pages: Deploy from a branch > main > /(root).
3. Hapus file dan 24 folder kitab versi lama yang TIDAK ada lagi dalam ZIP ini. GitHub browser upload tidak otomatis menghapus file lama. Jika tidak memungkinkan hapus sekaligus, hapus direktori kitab lama secara manual; jangan hapus .git, .github atau CNAME.
4. Jangan upload KITAB MD.zip maupun SOURCE_MANIFEST_PRIVATE. Ini paket publik berisi ringkasan Indonesia dan gambar dari versi terdahulu saja.
5. Verifikasi setelah push: https://amangkitabb-lab.github.io/QIraah/, halaman katalog, dan tiga halaman kitab di HP.
6. GitHub Pages project subpath HARUS QIraah dengan huruf sama.
